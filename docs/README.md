## Documentation rules

- Link to primary official sources for changing technical facts.
- Add a verification date when publishing a temporary price, quota, or program rule.
- Never publish credentials, billing identifiers, private IP addresses, or account screenshots containing secrets.
- Keep provider-specific procedures separate from provider-neutral architecture.
- Update both landing pages when navigation or project scope changes.
