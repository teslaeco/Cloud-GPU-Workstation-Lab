# Industry use cases

## Game development

Unreal Engine editing, shader compilation, light baking, builds, AI opponent training, multiplayer load tests, and asset processing.

## AI and machine learning

Fine-tuning, reinforcement learning, evaluation farms, synthetic-data generation, and inference benchmarking.

## Architecture, CAD, and engineering

BIM visualization, GPU rendering, digital twins, photogrammetry, point clouds, and supported simulation workloads.

## Film, media, and VFX

Frame rendering, denoising, upscaling, compositing, animation previews, and encoding.

## Geospatial and remote sensing

Satellite-image processing, segmentation, object detection, terrain reconstruction, and change detection.

## Science and research

Parameter sweeps, numerical simulations, image reconstruction, and GPU-supported scientific tools.

## Suitability warning

Not every application works correctly on a virtualized GPU or Windows Server. Check application licensing, virtual-GPU support, hardware acceleration, USB requirements, and vendor support before committing to a platform.
